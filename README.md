# AlabRyuu

A personal kid game marketplace for Alab Ryuu. Forty-two colorful mini-games live here: tap a card on the home page and play.

Little Earth sits at the root. The other games live in `games/` as single HTML files (phone-first, big tap targets, no downloads). Make an avatar, then it shows up in Pet Park, Cookie Bakery, Number Train, Paint House, and Sky Hop.

Open `index.html` in a browser. Nothing to install. Nothing to deploy.
